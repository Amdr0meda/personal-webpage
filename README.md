## 🌐 Pagina web personal (Blog) 
Repositorio de mi página web personal, desplegada con **GitHub Pages** y creada con **Hugo** utilizando el tema **Doks**. La seguridad y el rendimiento están reforzados gracias a **Cloudflare**.  

## 🌟 Contenido del sitio  
La página está organizada en las siguientes secciones:  
- **Portada** — Presentación y acceso rápido a las distintas áreas.  
- **Blog** — Publicaciones semanales.  
- **Documentación** — Guías, herramientas, configuraciones. 
- **Sobre mí** — Espacio donde comparto quién soy, mi trayectoria y mis intereses tecnológicos.  

## ✍️ Publicaciones semanales  
Mi objetivo es contribuir con **nuevos posts cada semana** y mantener el contenido actualizado.
